# Макеты PuzzleUp

Выгрузка артбордов холста Claude Design (https://claude.ai/artifact/L8cLVKc6K6RC48NqEY8vKo) от 11 ноября 2026. Каждый файл – статичный HTML с инлайн-стилями: точные размеры, отступы, цвета, шрифты и тексты макета. Открывается в браузере как есть.

## Как пользоваться

- Перед вёрсткой блока открой его десктопный (`D-*`, `T-*`) и мобильный (`M-*`, `TM-*`) файл и переноси раскладку, размеры и цвета на токены из `docs/design-system.md`.
- **Тексты, юридические формулировки и поведение берутся из ТЗ** (`docs/spec/*`), а не из макетов. Известные расхождения перечислены в `docs/design-system.md`, раздел 9.
- Ширина артбордов фиксированная: десктоп – 1280 px, телефон – 390 px. Промежуточные ширины (768, 1024) описаны в ТЗ, в макетах их нет.
- Не копируй инлайн-стили в код: переводи их в классы Tailwind и токены ДС. Значения, которых нет в шкале ДС, сначала сверяй с ТЗ.
- `ds/DS-Components.html` собран из вложенных компонентов холста (`<dc-import>`), вне холста они не отрисуются. Сами компоненты лежат рядом: `ds/Button.html`, `ds/Chip.html`, `ds/Sheet.html` и другие. Их параметры описаны в `docs/design-system.md`, раздел 6.
- `canvas.json` – карта холста: страницы, названия и порядок артбордов.

## Файлы

| Префикс | Что | Файлы |
|---|---|---|
| `D-` | Главная, десктоп 1280 | `D-1-hero` (шапка + первый экран), `D-5-tutors`, `D-2-situations`, `D-3-how`, `D-4-subjects`, `D-6-reviews`, `D-7-prices`, `D-8-faq`, `D-9-about` (блок «О сайте»), `D-10-footer` |
| `M-` | Главная, телефон 390 | те же блоки: `M-0-1-hero` … `M-10-footer` |
| `T-` | Страница репетитора, десктоп | `T-1-profile`, `T-2-about`, `T-3-outside`, `T-4-reviews`, `T-5-how`, `T-6-form`, `T-7-more` |
| `TM-` | Страница репетитора, телефон | `TM-1-profile` … `TM-7-more` |
| `T-S-`, `TM-S-` | Статусы репетитора | `*-full` («Мест нет»), `*-archived` (ушёл), `*-formfull` (форма листа ожидания), `T-S-statuses` (плашки) |
| `P-` | Служебные | `P-404-d/-m`, `P-privacy-d/-m`, `P-og` (OG-картинка 1200×630) |
| `X-` | Глобальные элементы | `X-header-d/-m` (шапка после прокрутки), `X-menu`, `X-bottombar`, `X-cookie-d/-m`, `X-form-errors`, `X-thanks-d/-m/-night` |
| `ds/` | Дизайн-система | `DS-Foundations`, `DS-Papers`, `DS-States`, `DS-Components`, компоненты `Button`, `Chip`, `Sheet`, `PuzzleStep`, `Doodle`, `SectionHead`, `Logo` |

Порядок блоков главной в макетах совпадает с ТЗ: шапка и первый экран, «Репетиторы», «Узнаёте ситуацию?», «Как это работает», «Предметы», «Отзывы», «Цены», FAQ, «О сайте», подвал.

## Обновление

Если холст поменялся, выгрузку нужно повторить. Попроси об этом в чате проекта PuzzleUp на claude.ai.
