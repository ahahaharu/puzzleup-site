## 8. Изменения в ТЗ главной, что не входит, открытые вопросы

**Что меняется в «ТЗ: главная страница PuzzleUp»** (внесено туда же):

- в карточке репетитора – только имя, плашка статуса занятости, стаж вместо «опыта»;
- порядок карточек – по статусу, затем по `order`;
- у карточки со статусом «Мест нет» кнопка – «В лист ожидания»;
- «Подробнее» ведёт на `/tutors/[slug]`.

**Не входит в первую версию.**

- Видео-знакомство с репетитором.
- Результаты учеников.
- Каталог `/tutors` с фильтрами – когда репетиторов больше 6.
- Расписание и свободные слоты по дням – только общий статус.
- Редактирование профиля репетитором через сайт: пока правка файла в репозитории.
- Отзыв через форму на сайте: пока отзывы собираются вручную, с согласия автора.
