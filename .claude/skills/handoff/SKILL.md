---
name: handoff
description: Сохраняет прогресс текущей фичи в описание PR перед очисткой сессии, чтобы следующая сессия продолжила с того же места. Запуск вручную - /handoff.
disable-model-invocation: true
allowed-tools: Bash(git *) Bash(gh pr create *) Bash(gh pr view *) Bash(gh pr edit *)
---

1. Закоммить готовые изменения – только то, что проходит `pnpm lint && pnpm typecheck && pnpm test`. Незаконченное не коммить: оставь в рабочем дереве и опиши в пункте «Незакоммичено».
2. `git push -u origin <ветка>`.
3. Если PR нет – создай черновик: `gh pr create --base develop --draft --fill-first`.
4. Обнови в описании PR раздел **Прогресс**:
   - **Сделано** – по пунктам, со ссылками на коммиты;
   - **Осталось** – конкретные следующие шаги в порядке выполнения;
   - **Контекст** – что важно знать следующей сессии: принятые решения, найденные подвохи, какие файлы ТЗ и макетов нужны;
   - **Незакоммичено** – если что-то осталось в рабочем дереве.
5. Ответь одной строкой: «Готово. В новой сессии: `/feature <пункт>`».
